# Arc USDC Quickstart

A minimal React + viem starter for sending USDC on Arc testnet (chain id 5042002).

## Quickstart
1. `npm install`
2. Set `usdc` in `src/config.ts` to the testnet USDC address.
3. Build the send-payment page: connect wallet, enter recipient + amount, call `transfer`.
4. `npm run check`, then `npm run dev`.

Built for Arc testnet. See CONTRIBUTING.md for local setup.
